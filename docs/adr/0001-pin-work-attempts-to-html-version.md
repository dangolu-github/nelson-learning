# Pin work attempts to their starting HTML version

Each autosaved draft and confirmed submission is rendered from the canonical homework HTML version active when that attempt began. Later homework edits must not change an existing attempt's questions, layout, response IDs, answers, or review context; a reopened revision starts a new pinned work version while preserving prior attempts.

The teacher surface resolves the saved version to trusted portal HTML and CSS, then inserts stored response values into the original controls. It never renders learner-supplied HTML.
